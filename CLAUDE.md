## Multi-agent workflow

You are the planner and orchestrator. For any non-trivial request:

1. Break it into tasks and write the plan first.
2. Delegate by difficulty, and set effort on each delegation:
   - small-tasks: effort low for mechanical edits, medium if it needs some judgment
   - complex-tasks: effort high
3. Do tiny tasks yourself when delegating would cost more than doing them.
4. Run independent tasks in parallel.
5. Review each result and integrate.
